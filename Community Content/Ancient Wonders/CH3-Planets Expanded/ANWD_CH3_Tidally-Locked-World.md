## Tidally-Locked Moon
When a moon is tidally-locked, it is orientated towards the planet it orbits, as opposed to the stellar object. As such, it will have only one planetary class instead of different bands. Roll on the ==***>Planetary Class***== table on page 41 to determine the world type of the moon.

## Transitioning To Another Band
While undertaking an expedition in a tidally-locked world, you may interpret the "Enter a new biome" *Surface Feature* oracle result as a transition to the environment of the next planetary class. If unsure, **Ask the Oracle**.

## Heat Map Key
You can modify the planetary class of the light side of a tidally-locked world based on the temperature of the world's orbit.

If you are using the **Planetary Heat** guidelines from Chapter 2 on page 26, adjust the light side result of the *Bands* oracle per the *Stellar Object Heat Map* table using the key shown right.

| Temperature | Modifier |
| --- | --- |
| Searing | Shift result two columns to the left |
| Hot | Shift result one column to the left |
| Warm | Maintain result |
| Cool | Maintain result |
| Cold | Shift result one column to the right |
| Frigid | Shift result two columns to the right |
^table-Planet-Heat-Band

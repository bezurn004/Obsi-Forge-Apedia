## Atmosphere, Life, And Settlements
Roll ==*>Atmosphere*==, ==*>Life*==, and ==*>Settlements*== for the planetary class of the surface environment and envision the results across the entire world.

## Transitioning To Another Layer
While undertaking an expedition in a karst world, you may interpret the "Enter a new biome" Surface Feature oracle result as a transition to either the surface or subterranean environment. If unsure, Ask the Oracle.

### Heat Map Key
You can modify the planetary class of the surface environment based on the temperature of the world's orbit.

If you are using the **Planetary Heat** guidelines from Chapter 2 on page 26, adjust the result of the *Surface Environment* oracle per the *Stellar Object Heat Map* table using the key shown right.

| Temperature | Modifier |
| --- | --- |
| Searing | Shift result two columns to the left |
| Hot | Shift result one column to the left |
| Warm | Maintain result |
| Cool | Maintain result |
| Cold | Shift result one column to the right |
| Frigid | Shift result two columns to the right |
^table-Surface-Environ-Heat-Adjust

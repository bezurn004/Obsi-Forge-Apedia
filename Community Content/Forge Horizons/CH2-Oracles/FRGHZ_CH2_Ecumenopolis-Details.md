## Oracle: Random City Complications
When you’re on an ecumenopolis planet and roll doubles on the challenge dice, or if you need a new obstacle or challenge for your adventures on that same sort of planet, roll once on the table below.

This oracle can also be used in place of the [[SF_CH3_Pay the Price|Pay the Price]] table when you’re on an ecumenopolis planet.

| dice: 1d100 | Result |
| :---: | --- |
| 1 - 4 | An explosion |
| 5 - 8 | Corporate scheme is revealed |
| 9 - 12 | Desperate people in debt |
| 13 - 16 | Energy lost/blackout |
| 17 - 20 | Extreme weather |
| 21 - 24 | Failing infrastructure |
| 25 - 28 | Failing technology |
| 29 - 32 | Hired assassin/mercenary |
| 33 - 36 | Local police |
| 37 - 40 | Private security |
| 41 - 44 | Riot/demonstration |
| 45 - 48 | Roving street gang |
| 49 - 52 | Smog/pollution |
| 53 - 56 | Someone is killed/injured |
| 57 - 60 | Something emerges from a lower level |
| 61 - 64 | Something falls from a higher level |
| 65 - 68 | Something is hacked |
| 69 - 72 | Something is stolen/pickpocket |
| 73 - 76 | Traffic |
| 77 - 80 | Trap is sprung |
| 81 - 84 | Troublesome machine |
| 85 - 88 | Vehicle problems |
| 89 - 92 | Witness or bystanders |
| 93 - 100 | Roll twice |
^table-City-Complication
